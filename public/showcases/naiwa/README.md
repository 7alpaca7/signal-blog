# NAIWA Atmospheric Gallery — 收敛滚轮惯性与画面边界版

以原生 HTML、CSS、JavaScript + Three.js/WebGL/GLSL 独立实现的景深画廊。

- 保留相邻作品 Z 轴间距 `5.40`、进出场整体倾斜、**之前版本的淡入淡出区间**以及轻微 GLSL 图片弯曲。
- 减小滚轮瞬时冲量、向下/向上漂移及速度缩放；弹簧接近临界阻尼，停止滚动不再明显过冲。
- 按真实透视相机、图片原始宽高比和旋转角度计算安全画面边界。需要时自动约束图像位置和尺寸，防止高速滚动及窄屏时被甩出视口。
- 保留三维风迹、粒子与氛围着色器。
- 奶蛙图片采用艺术宇宙站点在线直链，联网才能加载。Three.js 同样通过 CDN 加载。若遇 CDN 或 WebGL 受限，会启用页面内的图片降级展示。

## 运行

联网后使用 Chrome / Edge 打开 `index.html`。若浏览器阻止 `file://` 动态模块加载，可在工程目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/`。无 Vue / React / Vite，不需要安装 npm 依赖。
