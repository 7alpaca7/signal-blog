## 在线体验

这是一条独立前端交互作品记录，列表与创作足迹直接打开景深画廊。使用滚轮、触摸拖动、方向键或画面中的切换按钮浏览作品。

## 设计与交互

画廊沿 Z 轴组织图像，保留相邻作品 5.40 的空间间距、进出场倾斜、淡入淡出、轻微 GLSL 图片弯曲，以及三维风迹、粒子和氛围着色器。

本版减小滚轮瞬时冲量、上下漂移和速度缩放，使弹簧接近临界阻尼。作品按透视相机、图片比例和旋转角度约束位置与尺寸，目标是减少停止后的过冲及窄屏边缘越界；实际效果以体验为准。

## 源码与素材

源码在资源仓库的“前端视觉效果”分类下载，原始 ZIP 与 README 保留。无需 Vue、React 或 Vite；可使用本地 HTTP 服务打开 HTML。
