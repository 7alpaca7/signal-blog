## 3. 视觉 DNA、配色与设计参数

**风格关键词：**真实厚度、内部折射、局部菲涅耳反射、自然色散、地面焦散、单主光源、克制留白、精密商业 CGI。

| 必需的视觉机制 | 正确表现                         | 常见失败         |
| -------------- | -------------------------------- | ---------------- |
| 透明介质的体积 | 边缘有厚度、内部透射/折射区别    | 果冻或塑料薄片   |
| 光路逻辑       | 主光源—透明体—焦散接收面一致     | 随机亮线         |
| 主体关系       | 核心对象清晰；玻璃是辅助层       | 玻璃装饰压过主体 |
| 色彩纪律       | 统一冷暖基调，仅局部色散         | 满屏虹彩与霓虹   |
| 版面层次       | 主体、背景、焦散、留白有明确职责 | 悬浮素材堆叠     |

### 推荐参数（设计建议值，不是原作实测）

| 参数       | A：几何原创               | 奶蛙 B：角色风格迁移                  |
| ---------- | ------------------------- | ------------------------------------- |
| 画幅       | 16:10 / 16:9 / 4:5        | 推荐 4:5 竖幅                         |
| 主体大小   | 占画宽约 35%–60%          | 奶蛙占画高约 55%–75%                  |
| 透明介质   | 1–3 件                    | 优先 1 条玻璃弧带                     |
| 焦散占比   | 约 15%–45%                | 地面约 15%–35%，不可遮挡脸部          |
| 光源       | 单一清晰主光 + 微弱环境光 | 左上方主光，可少量暖色边缘光          |
| 保真优先级 | 材质与光影                | 奶蛙轮廓 > 眼睛嘴巴 > 肚皮 > 光学效果 |

### 推荐配色（非官方精确取样）

| 调性         | 背景                     | 深色辅助       | 光学高光   | 主体色                   |
| ------------ | ------------------------ | -------------- | ---------- | ------------------------ |
| 冷调科技光学 | `#E9FAFF`                | `#163D57`      | `#84D6E8`  | 依实际题材               |
| 暖调艺术玻璃 | `#F5F0E8`                | `#926F7C`      | `#F2CAB6`  | 依实际题材               |
| 奶蛙主题     | 浅蓝灰（参考 `#CAD9E9`） | 蓝灰 `#6A8CAD` | 冷白与微金 | 保持奶蛙原始黄色和奶白色 |

**注意：**奶蛙的黄色和奶白色属于角色识别信息，应高于整体色板要求；光学风格不能把奶蛙重新染成蓝色或透明。

## 4. 完整提示词 A：从零生成

使用时替换主题、对象、文字、比例、色彩。完整提示词见下方代码块。

```text
你是一名精通当代数字艺术、光学摄影、三维材质表现和高级平面设计的视觉艺术总监。

请根据我提供的主题，创作一幅具有 Optical Caustics & Refractive Glass Art Direction（光学焦散与折射玻璃艺术）风格的原创高完成度视觉作品。

【创作输入】
设计主题：【填入主题】
核心对象：【填入对象；若无，由你根据主题合理设计】
必须呈现的文字：【没有则不添加】
输出比例：【4:5 / 1:1 / 16:9 / 自定义】
色彩方向：【冷调冰蓝 / 暖调艺术玻璃 / 自定义】

【视觉主体】
根据主题选择一个具有明确轮廓与结构的透明或半透明物体；可以是抽象几何、真实物体、原创文字装置或主题相关结构。不要默认选择玻璃球、透明环或任何固定品牌符号。

透明材料具有真实厚度、边缘反射、内部折射、透射率变化和适度的局部色散。物体不同厚度的区域应产生不同程度的光学形变，不能全部呈现均匀透明度。

【光与焦散】
设定一个明确的主光源方向。光线穿过透明物体后，在附近的底面、墙面或其他接收面上产生连续、有方向、有聚散规律的焦散亮纹。亮纹的方向、形态和明暗变化应与主体的轮廓、曲率及光源位置相呼应。

焦散以精细的光学弧线、自然聚焦的亮纹、局部高光与暗部过渡构成。避免随机光带、霓虹曲线和不符合物体空间关系的投影。

【构图】
使用现代、克制而具有视觉张力的构图。优先选择少量主体，突出大尺度留白、适当偏心、边界裁切或近距离材质特写。让透明物体与焦散共同构成画面视觉中心，不通过随机增加装饰物制造复杂度。

【色彩】
以一个主色系和中性背景为基础。冷调可使用深蓝黑、冰蓝和接近白色的高光；暖调可使用烟粉、杏色、浅琥珀和奶油色。只在玻璃边缘及强折射区域加入少量自然色散，不要让虹彩覆盖整幅画面。

【材质与完成度】
表现清晰的边缘、玻璃厚度、菲涅耳反射的视觉特征、可信的内部折射、微弱表面瑕疵和精细光影层次。光源、物体与接收面的空间关系必须一致。追求高水平商业 CGI 和当代数字艺术的完成度，不追求无意义的复杂度。

【文字】
如果输入需要文字，使用清晰、现代的无衬线编辑式排版。主要信息必须可读；装饰性文字允许少量折射，但不能影响重要文案。没有文字要求时不主动编造标语、品牌名称、日期或技术参数。

【禁止】
禁止玻璃拟态UI、磨砂卡片、悬浮圆角组件、廉价塑料/果冻感、随机透明球、赛博朋克背景、大面积虹彩渐变、无意义发光条、过度镜头光晕、伪技术HUD、金属塑料混搭、随机英文、模板化科技海报。

【最终要求】
直接生成完整图片，不输出代码。保留题材自由，重点让真实厚度的透明介质、受控折射与焦散成为视觉语言。不要复制任何参考作品的标志、文案或固定构图。
```

## 5. 完整提示词 B：通用原图重绘

适用于产品照片、人物、海报、已有设计图。先上传图片，完整提示词见下方代码块。

```text
请担任精通当代实验性平面设计、真实玻璃材质与光学摄影的视觉艺术总监。

我已经上传一张原始图片。请把它重绘为 Optical Caustics & Refractive Glass Art Direction（光学焦散与折射玻璃艺术）风格。

这是原图风格转换任务，不是以原图为灵感重新创作无关的新场景。

【最高优先级：内容保真】
保留原图的主题、主体身份、关键物体轮廓、重要空间位置、文字、数字、图例、连接关系和信息层级。禁止删除、杜撰或替换关键信息。对于图表和技术结构，不得修改节点、方向、公式与数据含义。

【材质转换选择性】
先判断哪些主体或背景区域适合玻璃化。只对适当区域添加透明材料、厚度、局部折射和边缘反射。不要强制将原图中全部物体都变成玻璃，也不要将人物、自然物体或关键技术组件无差别转换为透明塑料。

【构图约束】
尽量保持原图核心主体的比例、位置及相互关系。可以调整背景、负空间、光照和局部材质质感，但不能任意改变内容结构。所有新增玻璃元素必须服务于原主题；不得随意加透明环、球体、随机装置。

【焦散光效】
建立一个一致的主光源。让光线穿过透明介质，在附近背景或承接表面形成连续、真实、与物体几何关系相符的焦散亮纹，包含聚焦、扩散、阴影和局部的微弱色散。

【配色】
在保留原图必须存在的语义颜色基础上，使用统一的冷色或暖色美学；通过高光、透明度、折射与材质变化增加层次。避免强制把所有颜色改成荧光蓝或全彩虹渐变。

【文字保护】
所有重要文字、数字、公式、说明和图例必须准确清晰。如果文字处在折射玻璃之后导致可读性下降，应把它放回清晰的信息层。不要生成伪中文或看起来相似却内容错误的文字。

【质感】
玻璃应有真实厚度、精细轮廓、可信的内部折射和局部反射。自然主体需要保留其原有材质，避免变成果冻或充气塑料。焦散应和受光面相互作用，而不是成为漂浮在空气里的装饰线。

【禁止】
禁止改动原主题、关键信息、原始数字与逻辑关系；禁止完全重构主体；禁止玻璃拟态UI、漂浮卡片、随机球体、赛博朋克、虚假HDR光晕、伪技术HUD、过度彩虹、塑料感、随机英文和复杂无意义背景。

【最终要求】
直接输出完整的风格重绘图片。在不损害原图内容的前提下，通过有选择的透明介质、真实折射、受控光线和焦散投影建立新的视觉风格。不要复制具体参考作品的商标、品牌或文案。
```

## 6. 完整提示词 C：奶蛙专用重绘

**推荐实际操作：**先把 `/images/optical-caustics/milk-frog-reference.png` 上传给 GPT Image，再发送下面整段文字。它比通用 B 更重视角色本身。完整提示词见下方代码块。

```text
你是一名擅长角色保真编辑与当代光学焦散艺术指导的视觉设计师。我已经上传了【奶蛙参考图】；以这张图片为角色身份和外形的唯一依据，请创作一张 Optical Caustics & Refractive Glass Art Direction 风格的高质量视觉图像。

【第一优先级：锁定角色】
角色是奶蛙，不是一般青蛙，也不是重新设计的卡通怪兽。精确保留参考图的黄色、圆润梨形身体（上窄下宽）、几乎和头身融为一体的轮廓、占据下半身的大面积奶白色椭圆肚皮、头部正面靠近顶部的两只小圆眼睛（带细小绿色眼圈）和短小、平缓的微笑。两侧肢体非常短、贴合身体，避免夸张突出的手、脚、眉毛、牙齿、鼻孔或眼眶。保留原本憨厚、呆萌而平静的表情，不要把眼睛做得很大、很凸出。

【材质保护】
奶蛙的身体保持柔和的黄色哑光或微微柔光材质，肚皮保留柔和奶白色，不要将奶蛙本体变为透明玻璃、液态金属或光亮塑料。

【光学风格迁移】
```
