这篇日志整理 SIGNAL 当前已经完成的工程建设。发布日期是本次整理入库的时间，不代表每项工作的精确发生时刻。

## 从概念稿进入真实页面 {#start}

这个网站最初从创意开发者博客的视觉方案开始：深色背景、黄绿色像素角色、街机风格，以及有重量感的交互。随着首页、全部记录和详情页的流程明确，项目进入 Vue 3 + JavaScript 的实现阶段。

目前已经接通首页最近记录、归档分类与话题筛选、文章详情和不存在页面的反馈。首页与归档里的文章都进入同一套详情组件，避免两种入口出现不同的阅读体验。

## 把职责放到合适的位置 {#boundaries}

工程采用应用、页面、业务模块和公共能力的分层方式：

```text
src/app       应用装配、布局、路由
src/pages     首页、归档、详情的组合
src/modules   文章、文档活动、阅读、互动
src/shared    小黄脸、背景、动效、基础 UI
src/data      具体内容适配器
content/posts 博客 Markdown 原文
```

页面通过 repository 获取内容，不直接读取 Markdown 文件。具体适配器由应用装配；服务的公开入口与 UI 入口分开，避免安装数据服务时就提前加载所有页面组件。

## 先建立可执行的工程约定 {#quality}

组件使用 Composition API 和 `script setup`，业务源码保持 JavaScript。JSDoc、vue-tsc、ESLint 和 Prettier 共同约束类型、依赖方向和格式；Vitest 与 Playwright 覆盖关键业务和浏览器流程。

公共接口写明用途，复杂规则用中文注释解释原因。RAF、定时器、观察器和事件监听均需要明确的释放路径。

日常修改后运行：

```sh
npm run check
npm run test:e2e
```

这些命令分别覆盖静态检查、单元测试、演示构建和浏览器回归。测试数量会随项目变化，这里不把某一次运行结果当成永久保证。

## 当前阶段的边界 {#next}

当前重点仍是前端展示。评论、真实的全站点赞累计和后端身份系统尚未接入；正式发布还需要处理部署路径、路由回退与搜索收录。工程已经留下数据接口边界，但没有把规划能力当作已完成功能。
