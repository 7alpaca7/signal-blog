这篇日志汇总目前已实现的角色和动效设计。它是当前实现的整理，不是按文件保存次数生成的修改历史。

## 一个角色，贯穿多个场景 {#character}

SIGNAL 的小黄脸不只是一张装饰图。首次加载、页面切换、首页交互和文章点赞都使用它，让这些原本分散的反馈形成统一的角色语言。

| 场景     | 当前动作                               |
| -------- | -------------------------------------- |
| 首次进入 | 举起红色 COLA 杯、喝下、满足微笑、放杯 |
| 站内换页 | 同一版可乐动作压缩为约 1.8 秒转场      |
| 首页     | 间歇同时喝可乐、雪碧、芬达             |
| 全部记录 | 间歇喝芬达，点击出现害羞爱心           |
| 文章点赞 | 会话内切换点赞状态，角色喝雪碧         |

首次开场保留约 5.6 秒的完整动作，内容就绪后可以跳过。系统设置减少动态效果时直接进入页面。

## 三杯汽水共用一条动作时间线 {#three-drinks}

首页的小黄脸现在会把三杯汽水一起举起。红、绿、橙色杯身分别标有 C、S、F，三路吸管汇到嘴边。三杯使用同一个举杯进度，避免各自计时导致动作错位。

画布只在底部增加必要的像素空间，脸和左手的大小保持不变。举杯之前的三杯也能完整显示，不会从边缘被切掉。

## 基础动作和点击反馈分开 {#feedback}

喝汽水属于基础动作，比耶、腮红、爱心和彩虹属于叠加反馈。点击不会重置喝饮料的时钟，也不会把喝下阶段的嘴型替换成另一张表情。

首页的比耶手放在左边，右侧留给饮料。彩虹绘制在角色容器之外；入场遮罩只作用于画布，避免把彩虹截断。

## 背景持续运动，也要允许停下来 {#background}

背景包含缓慢变化的像素点阵、阶梯轨迹、移动光点和点击扩散。数字烟花按活跃时间每 5 秒发射一批，每批随机 1–5 枚，大小、颜色和位置在创建时确定。

动画通过共享 RAF 调度，离屏或后台时暂停。全屏开场与转场遮住内容时，背景也暂停工作，恢复后不补发遮挡期间的烟花。

所有主要动效时间参数集中在 Motion Tokens。后续调整节奏时，应先修改这些参数，再观察页面整体的重量、速度和回弹是否协调。
