# 实施顺序与交付边界

## 当前完成

已建立 Vue 3 + JavaScript 工程、服务注入、懒加载路由、应用布局、首页/归档/基础详情/404、演示文章、URL 筛选与异步资源生命周期。代码检查、单元测试、端到端测试及 CI 配置已加入；实际验证结果见本次交付说明。概念稿的完整视觉与动态表现仍在后续阶段还原。

## 最近验证

- npm run check：通过格式、依赖边界、JavaScript/SFC 检查、19 项单元测试与演示构建。
- npm run test:e2e：桌面与窄屏合计 14 项回归通过。
- 默认生产构建拒绝演示数据的保护已验证。
- 本地 Vite 页面已通过浏览器检查，无运行错误。

## 阶段 1：工程底座

建立 Vue 3 + JavaScript / Vite 工程，锁定工具链、补全 npm scripts，配置 Router、Pinia、JSDoc 检查、lint/format、测试与 CI。

建立应用布局、404、基础样式 tokens、服务装配与 mock 模式标识。只创建当前使用的模块，不生成目录树里所有空文件。

验收：干净安装后 check 通过，开发服务可打开，深路径刷新在本地预览环境可用，依赖边界规则生效。

## 阶段 2：业务主流程

定义文章与活动契约，整理示例数据；实现首页、归档过滤与 query、统一详情模板、来源返回与位置恢复、异常状态。

验收：首页和归档进入同一详情组件；刷新可恢复筛选；浏览器前进后退行为正确；接口延迟/失败、空结果和不存在的文章均有明确反馈。

## 阶段 3：阅读与互动

接入目录跟随、进度与像素滚动条、字号和配色；实现文章独立的点赞、评论与回复。mock adapter 的交互标识清楚，真实 adapter 留在契约边界后实现。

验收：正文、目录、滚动条使用一致滚动源；连续切换文章不串数据；评论失败保留草稿；重复操作不会重复提交。

## 首页文档打卡恢复

创作足迹已接入独立 activity 模块，支持按月贡献热力格、日变更列表、新增/修改统计、空日期提示、未来日期禁用和对应文章跳转。统计按北京时间，每条文档变更日志计一次，数据明确为示例。日期/闰年/聚合单元测试与桌面/手机端 2 项流程回归通过。

## 页面角色差异化

首页：间歇喝雪碧，点击比耶眨眼，叠加爱心和彩虹。归档：间歇喝芬达，点击害羞爱心。状态实例独立，喝饮料时点击不重置时钟。新增差异化与原芬达兼容回归在桌面/手机端共 4 项通过。

## 原版可乐开场恢复

已复用原确认稿的 128×128 renderer：红色 COLA 杯、对齐嘴部的吸管、举杯/闭眼喝下/满足/放杯。首次默认完整 5.6 秒，可跳过；减少动态效果直接进入。开场期间隔离底层交互，退场后恢复主标题焦点；站内切换仍使用独立紫灰转场。

## 动效恢复进度

已接入统一帧调度、后台/离屏暂停、动效开关与系统减少动态效果；背景、烟花、芬达/可乐/雪碧、点击爱心腮红、惯性跟随、方向 hover、列表归位、遮罩入场及紫灰路由转场。详情阅读反馈与演示点赞已接入。正式后端、评论和最终视觉细节仍需继续完成。

## 阶段 4：视觉与动态还原

依据已确认设计实现首页/归档/详情；提取统一角色 renderer 与基础/反馈双轨状态；接入加载、转场、背景、烟花、惯性跟随和方向感知 hover。

验收：烟花每 5 秒随机 1–5 枚；芬达播放后恢复；点击爱心和腮红不打断喝芬达；点赞喝雪碧；关闭动效与减少动态效果可用；往返页面无资源累积。

动效基础设施可在阶段 1 按需要建立最小接口，具体效果在本阶段落地，避免先搭没有使用场景的通用框架。

## 阶段 5：真实接入与发布准备

确认内容来源、评论身份/审核、点赞规则、活动口径和部署环境，再实现 HTTP adapter。核验安全、性能、SEO、托管回退与缓存策略。

验收：生产无误用演示内容；真实写操作的失败、重复、权限与审核状态正确；发布配置和验证记录完整。

## 尚需产品确认、但不阻塞骨架的事项

1. 首页直达文章后的返回行为：规划默认回到首页来源位置。
2. 文档活动某日记录是否可直接打开对应文章；一次提交还是每篇文档变更为统计单位。
3. 文章来自本地 Markdown、CMS 还是自有 API；正文更新与发布方式。
4. 匿名评论、登录、审核、回复层级与删除能力。
5. 点赞按账号还是匿名标识去重。
6. 正式域名、部署方式与搜索收录要求。

## 本地 Markdown 内容接入

文章源迁移至 content/posts/；列表、详情、分类/标签和首页活动统一从 Markdown 派生。构建校验、草稿过滤、正文安全净化、目录锚点和详情拆包已实现。修改历史使用显式 revisions，不以文件保存次数推断。写作规范见 content/README.md。此项不引入后端与生产部署。
