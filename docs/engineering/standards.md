# 工程规范与验收标准

代码解耦、扩展、命名、格式和注释的具体要求以 [代码质量与维护规范](code-quality.md) 为准。

## 工具链与依赖

Vue 3、JavaScript、Vite、Vue Router、Pinia 为基础。包管理采用 npm，提交 package-lock.json，CI 使用 npm ci。初始化时校验工具链声明的 Node 支持范围，再固定 Node 与 npm 版本；本规划不臆定最新版本号。

工具配置规划：ESLint（含 Vue 规则与依赖边界）、Prettier、Vitest + Vue Test Utils、Playwright。Markdown 渲染与安全处理依赖在详情页阶段按实际内容格式选择。避免默认引入大型 UI 库、多个动效库、日期工具全集或全局查询框架。

JSDoc + jsconfig `checkJs` 提供 JavaScript 静态检查；Vue SFC 检查由 vue-tsc 执行，允许工具链依赖 TypeScript，但业务文件保持 `.js` 和 `.vue` 的 JavaScript。

## 编码约定

- Vue 组件 PascalCase；JavaScript 文件 kebab-case；composable 文件 use-xxx.js、导出函数 useXxx；组件事件表达业务意图。
- 单个组件只承担一种清晰职责；拆分依据是状态与行为边界，不机械追求行数。
- 全局样式只包含 reset、tokens、基础排版；组件样式 scoped，禁止任意跨组件深选择器。
- UI 组件通过 props 接收数据，通过 emits 发出动作；不在通用按钮内写路由或请求。
- 不使用魔法字符串标识业务状态；枚举集中在所属模块。金额、时间、分页等边界值显式校验。
- 常量、函数和服务命名描述具体职责，不建立不断堆积的 utils.js、common.js、globalStore.js。
- 异步结果要处理取消、失败与竞态；事件监听、observer、RAF、timer 均在作用域退出时清理。
- 所有演示文章与互动数据明确为示例；真实接入前不声称已同步或已持久化到服务端。

## 交互与无障碍

原生按钮、链接、表单保持正确语义；路由跳转用 RouterLink，按钮用于动作。所有主要操作支持键盘，保留可见焦点；评论校验反馈与表单关联。菜单/抽屉管理焦点与 Escape，导航完成把焦点交给主标题。

可关闭动效；系统减少动态效果优先于默认自动播放。点击反馈可改为短时静态状态。Canvas 不承载独有业务信息；点赞状态、进度与评论结果有文本语义。避免频繁播报动画帧。

320px 到桌面宽度不发生横向溢出，移动端触控目标原则上至少 44×44 CSS px；正文对比度按 WCAG AA 核验。

## 测试边界

对关键逻辑和回归风险测试，不为静态布局或简单属性透传制造大量测试。

- 单元：组合筛选、query 归一化、跨月与时区聚合、评论校验、角色双轨状态、烟花批次数量和调度。
- 组件：提交失败保留输入、点赞失败回滚、切换文章不串状态、减少动态效果分支。
- 端到端：从首页与归档进入同一详情；筛选后返回保留 query/位置；目录/hash/滚动进度一致；评论与回复；404、接口失败和重试。
- 视觉检查：桌面与窄屏的首页/归档/详情，深浅阅读模式，加载转场、芬达动作叠加爱心、烟花节奏。随机效果可固定种子供回归截图使用。
- 资源检查：路由往返和后台恢复不累积 RAF、事件和定时器；重复点击不产生无界粒子或重复请求。

## CI 与命令契约

工程已配置下列脚本，执行结果以实际运行记录为准：

| 脚本            | 用途                                                   |
| --------------- | ------------------------------------------------------ |
| dev             | Vite 开发服务                                          |
| build           | 生产构建                                               |
| preview         | 本地检查构建产物                                       |
| lint            | ESLint，无自动修改                                     |
| format:check    | 格式检查                                               |
| format          | 显式格式化                                             |
| typecheck       | JavaScript/JSDoc 与 Vue SFC 静态检查                   |
| test:unit       | Vitest 单次执行                                        |
| test:unit:watch | 单元测试监听                                           |
| test:e2e        | 关键流程浏览器回归                                     |
| check           | lint + format:check + typecheck + test:unit + 演示构建 |

CI 在干净环境执行安装、check 和必要的 e2e；失败保留浏览器 trace 与截图，不上传用户输入、凭据或整段敏感响应。环境变量示例只记录公开配置名称和含义，不提交密钥。

## 性能验收

首次内容与导航优先于装饰效果；详情正文按路由拆包，避免首页加载全部文章和代码高亮资源。高亮按需加载，字体有回退方案，图片减少布局偏移。

上线前在约定设备与网络条件记录 LCP、INP、CLS 和动效帧耗时，目标参考 LCP ≤ 2.5s、INP ≤ 200ms、CLS ≤ 0.1；没有实测就不宣称达标。动画出现压力时先降低粒子数量、DPR 与帧率，不削弱文本交互，也不改变 5 秒、1–5 枚的已确认业务规则。

## 完成定义

功能完成须同时具备：业务状态与异常路径、视觉一致性、响应式与键盘可用、资源清理、必要测试、构建检查、文档与配置更新。只有静态截图一致不能视为业务完成。
